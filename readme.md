# Projeto Excessos do Estoque

Aplicação web desenvolvida para praticar conceitos de desenvolvimento front-end e back-end através de um sistema de controle de movimentações de estoque.

## Sobre o projeto

A ideia deste projeto surgiu a partir da observação de uma necessidade real no ambiente de varejo: facilitar o registro de entradas e saídas de produtos excedentes do estoque.

O objetivo é desenvolver uma interface simples e intuitiva, permitindo que o vendedor/assistente informe o modelo do produto, tamanho, tipo de movimentação e quantidade.

O projeto está em desenvolvimento e também faz parte do meu processo de aprendizado em programação.

## Funcionalidades atuais

- Formulário para registro de movimentações
- Registro de entrada ou saída
- Informação de modelo, tamanho e quantidade
- Interface responsiva para computadores e celulares
- Comunicação entre formulário HTML e back-end Flask
- Processamento dos dados enviados pelo formulário

## Tecnologias utilizadas

- Flask
- HTML
